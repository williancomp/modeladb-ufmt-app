# History of failures found by the evaluation

Files here record the initial runs of the experiments, before the corresponding exporter bugs were fixed.
They are not regenerated by `npm run evaluate`; the current tables live in `../results/`.

- `ddl_before_fixes.txt`: DDL conformance run before the reserved-word, single-table-inheritance
  surrogate-key, duplicate-foreign-key and accent-transliteration fixes.
- `targets_*_before_fixes.csv`: ORM/schema target checks before the Prisma, Django, GraphQL and Laravel
  exporter fixes (all 14 Prisma and all 14 Django outputs were rejected by their tools; 2 GraphQL outputs
  were rejected).
